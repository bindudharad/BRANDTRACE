# BRANDTRACE — Frontend Integration & Visual Intelligence Workspace

## Overview

The Reference-Based Logo Intelligence subsystem is seamlessly integrated into the BRANDTRACE web client (`src/`), providing compliance officers, brand managers, and designers with an interactive, real-time visual compliance auditing environment.

## 2. Five Unified Workspace Tabs

### Tab 1: Verify Document Logo (`verify`)
- **Multi-Format Ingestion:** Accepts single images (PNG, JPEG, WebP) and multi-page vector/raster PDF files.
- **Verdict Banner:** Displays top-level status (`COMPLIANT`, `PARTIALLY_COMPLIANT`, `NON_COMPLIANT`, `NEEDS_REVIEW`).
- **PDF Page Navigation:** Interactive page selector (`Page 1`, `Page 2`, ...) allowing compliance officers to jump between pages and inspect page-specific mark detections.
- **Side-by-Side Comparison:**
  - *Left Card:* Official Approved Reference metadata (Name, Variant, Target Aspect Ratio, Version, Approved Palette).
  - *Right Card:* Detected Mark details (Observed Aspect Ratio, Deviation %, Pixel Dimensions, Physical Dimensions in Points and Millimeters for PDFs).
- **Difference Heatmap Overlay:** Renders high-contrast base64 structural difference heatmaps generated by the backend engine, visually highlighting modified logo areas.
- **Numerical Evidence Grid:** Shows compliance status for Identity, Aspect Ratio, Cropping, Color, Size, Clearspace, and Placement.
- **Actionable Findings Stream:** Lists page-specific violations with expected standards, observed values, and a one-click **"Resolve"** button that updates disposition state via `/api/logo-intelligence/findings/{id}/resolve`.

### Tab 2: Official Logo Reference Library (`references`)
- **Reference Catalog:** Grid of official brand references registered in the active workspace.
- **Metadata Cards:** Displays high-resolution preview, Variant badge (`Primary Horizontal`, `Vertical`, `Symbol`, `Monochrome`, `Reversed`, `Partner Lockup`), SHA-256 fingerprint, dimensions, and aspect ratio.
- **Color Swatches:** Displays extracted dominant brand colors with interactive hex code chips.
- **Governance Controls:**
  - One-click **Approve** and **Deactivate** buttons enforcing organizational governance.
  - **Register Official Logo Form:** Expandable drawer to upload new logo artwork, specify variant, category, description, and auto-approve.
  - **Seed Nexus Logistics Standards:** Instant demo seeder populating the workspace with the complete canonical suite of approved references.

### Tab 3: Logo Standards & Rules Editor (`standards`)
- **Reference Selector:** Switch between different approved reference marks to tune their specific parameters.
- **Interactive Controls:**
  - *Aspect Ratio Tolerance Slider:* Calibrate allowable deviation (default 5.0%).
  - *Digital Dimensions:* Min digital width and height inputs (px).
  - *Print Dimensions:* Min physical print width in typographic points (`pt`) and millimeters (`mm`).
  - *Clearspace Margin Slider:* Calibrate perimeter exclusion ratio ($M \ge 0.50H$).
  - *Color &Delta;E Tolerance Slider:* Set CIE76 color distance threshold (default 16.0).
  - *Permitted Quadrants:* Restrict allowed placements (`ALL`, `TOP_LEFT`, `TOP_RIGHT`, `HEADER_ONLY`, `BOTTOM_RIGHT`).
  - *Every-Page PDF Enforcement:* Toggle requiring approved logo presence on every page of multi-page PDF documents.

### Tabs 4 & 5: Typography & OCR Extraction (`typography`, `ocr`)
- Preserves full document typography font verification and EasyOCR document text extraction capabilities.
